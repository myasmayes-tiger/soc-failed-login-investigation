# SOC Failed Login Investigation

## Project Overview

This project simulates a basic Security Operations Center investigation of repeated failed login attempts against a Windows user account.

The investigation used Windows Security event logs to identify failed authentication attempts, analyze the reason for failure, and determine whether the targeted account successfully authenticated afterward.

## Environment

- macOS host
- UTM virtualization
- Windows 11 Pro ARM64
- Windows Event Viewer
- Windows Security logs
- Local Security Policy

## Skills Practiced

- Security log analysis
- Windows Event Viewer
- Authentication event investigation
- Event ID 4625 analysis
- Event ID 4624 analysis
- Incident scoping
- Timeline review
- SOC documentation
